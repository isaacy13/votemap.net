# VoteMap spec

Start here. These files are the product record. How to build the app is in [AGENTS.md](../AGENTS.md).

- [requirements.md](requirements.md) is solved v0 only.
- [open.md](open.md) is unresolved. Three columns: name, problem, proposed solutions (not locked). Options stay in the third column.
- [later.md](later.md) is unfinished, not solved.
- [accepted-risks.md](accepted-risks.md) is decided and accepted, not later work.
- [STATUS.md](STATUS.md) is where the work stands (Building, Unfinished, Solved, Archived).

Do not invent rules. One pass keeps these files aligned.
