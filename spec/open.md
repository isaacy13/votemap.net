# Open questions

Not locked. Solved (v0 only): [requirements.md](./requirements.md). Known accepted risks: [accepted-risks.md](./accepted-risks.md). Later (not solved, unfinished): [later.md](./later.md).

| | | Proposed solutions (not locked) |
| --- | --- | --- |
| No taxpayer | Proposed mechanism if counsel says a form is owed: the signer tracks each payee’s calendar-year total and asks for a W-9 (through a vendor, never stored raw) before signing a pay that crosses the threshold. A pay moves USDC from the voter’s locked deposit to a person. Legal name is not collected. The trail has a handle and a wallet. The voter directs each pay, but votemap signs each one. Research on what the law may require: [legal-reporting.md](./legal-reporting.md), written for the old factory. |  |
| Gas sponsorship | Users pay Base gas on each deposit and pay, so a new user needs ETH on Base as well as USDC. A paymaster could pay that gas for smart-wallet users (cents per pay, our cost). | 1. Users pay their own gas. 2. votemap sponsors pay gas through a paymaster, capped per account per month. |
| Treasury key | Tips go to the treasury wallet. If one key controls it, losing or leaking that key loses every tip. (The PotVault audit is no longer optional: it holds money, so requirements item 11 requires one before launch.) | 1. Treasury is a 2-of-3 multisig (Safe on Base). 2. Single-key treasury. |
| Locked pot legal review | Pledgers now lock USDC in the PotVault until their expiry. VoteMap has no key that moves it, but its signer must approve each pay, so it can block a pay (never take one). Counsel must say whether that makes VoteMap a money transmitter or escrow agent before launch. FinCEN’s 2019 guidance on DApps and unhosted wallets is the starting point; [legal-reporting.md](./legal-reporting.md) was written for the old factory. | 1. Keep the vault as specced and get the counsel read. 2. If counsel objects to the signer gate, make pays from a deposit need only the pledger’s wallet (VoteMap’s rules then apply only to direct pays). |
| Social rename | A bind stores the network handle. If someone renames on X, Instagram, TikTok, or Threads and another person takes the old handle, payers who pick that handle reach the old owner until the next check, and the new owner cannot bind it. | 1. Bind to the platform’s permanent account id (oEmbed author id, OAuth user id, Instagram page id); the handle is display only. 2. Bind to the handle string. |
| Named trail privacy | The trail names who paid whom and links each social account to a wallet, which exposes that wallet’s whole on-chain history. For political pledges that can mean harassment or safety risk, and it may deter donors. | 1. Keep it fully named; warn at wallet link and suggest a fresh wallet. 2. Payers can show as “anonymous pledger” on the page; the wallet stays visible on Basescan; payees stay named. |

v0 pricing is in [requirements](./requirements.md) item 10. No percentage is used to steer behavior.
