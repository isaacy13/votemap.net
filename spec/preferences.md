# Preferences

- 2026-09-29: Sign in with Google / Apple must be **true pills** matching **Browse**. Official marks + label **centered as a group** in the pill (not left-jammed). Fresh full-page screenshots, not tight crops of old UI.
- 2026-10-02: Bio bind is **bio only**. Either `votemap.net/handle` or `votemap/@handle` in the bio → that social is **verified for 60 days**, until we check again. A **daily job** re-fetches only due binds (bio and a bound website). Still there → another 60 days. Gone → bind lapses. **No comment fallback.** **No social OAuth, no cold-DM, no paid X API.**
- 2026-10-02: Shop must have an address, a website, or both. Vendor KYC / license stays later. Street stays unverified.
- 2026-10-03: Verified marks in v0 are only TikTok, X, Threads, and Instagram, via the bio rule (`votemap/@handle` or `votemap.net/handle` in that account bio, 60 days, daily job on due binds only), and a website only if that site itself shows `votemap/@handle` or `votemap.net/handle` (same two strings, same 60-day window, same daily job: re-check when due, string still there → another 60 days, gone → lapses; do not fetch early; do not verify every URL). A street address and any other link stay unverified. Showing the website on the public page is optional. Hiding it does not unbind it. After a check, the bind stays verified until the next check even if they remove the string or sell the account. Pay still goes to the wallet on that bind. That lag is accepted v0, not open. It applies to bio binds and to the website check. Legal name is not collected and is not a signup field.
- 2026-10-03: Known accepted risks live in [accepted-risks.md](accepted-risks.md).
- 2026-10-03: Stakes are for an outcome. The reward goes to the person who did the work (builder, writer, shop, advocate). v0 does not file lobbying disclosures. VoteMap does not run its own sanctions list; Coinbase screens those customers. OFAC lag is an accepted risk: VoteMap does not re-run the list and still must not knowingly pay a sanctioned person. Whether to screen politically exposed persons is open ([open.md](open.md)): v0 does not screen them today, and Coinbase country is not a PEP screen. A politician claiming a bounty is a separate open question: v0 does not yet forbid that payee.
- 2026-10-03: Shop on the public page is **v0**. **v0 shop is a catalog**, not only an address: products they sell (name, USDC price, physical or not, short text; off-chain, like links; not a token). Buyer spends that shop’s credit on a listed product. Redeem can name the product and the price. Do not tokenize the product listing. Redeem releases that price to that merchant. Not shipping labels, tax, themes, inventory sync, staff accounts, or a Shopify clone. License stays later. Solved v0: Redeem is final. Once the voter taps redeem, the shop credit USDC leaves the VoteMap factory and is paid to that merchant’s payout wallet. No VoteMap refund, no chargeback, no second hold, no two-step escrow after redeem. Redeem is the purchase, and it is final.
- 2026-10-02: Any add or change updates every doc and diagram that states the old rule in the same pass (requirements, flows, later, gaps, cheats, tweet-embed-filtering, v0 diagrams).
- 2026-10-03: Later is not solved. Solved means locked v0 only.
- 2026-10-03: v0 money trail: signer appends one row on stake / disperse / move / redeem with **action** (`stake` / `disperse` / `move` / `redeem`), from handle, to handle, amount, pot, tx hash. Page shows the action label. Names at that moment. Hash → Basescan. No-account hop is **unknown hands** (address, never a fake name). Visible-only score = share of these rows whose wallets are votemap accounts. No fee discount, rank prize, or new fee — economic reward stays in **Fees vs behavior**. Off-platform hops are not in this score. No archive node, no general USDC indexer. General hop explorer stays later (not solved).
- 2026-10-03: **Fees vs behavior** is open (whether locked rates + visible trail score make the wanted action cheaper). No new fee numbers. Exploit holes are named in [open.md](open.md), not a vague “not yet listed.”
- 2026-10-09: A shop cannot receive a bounty (shop disperse / redeem) unless it has at least one verified link and zero unverified links. An address-only shop or any unverified link cannot. A street address is not a link and does not by itself disqualify a shop. The public payee picker is unchanged.
- 2026-10-09: Shop URL fetch is solved v0, not open and not later. The signer fetches that URL on save only after the client check succeeded, and again when the 60 days are up. That 60-day check is server-only. The shop only learns whether the votemap tag was there. A same-host https URL is still fetched when that host is an address only the signer can reach. That is solved, not an open problem.
- 2026-10-09: A social profile URL or shop website URL that is already claimed is rejected, whether the existing claim is someone else’s or this same account. Comparison is case-insensitive. x.com and twitter.com are the same network. The bio token match stays case-sensitive. Do not fold www to apex. If a votemap tag check returns tag_missing, do not recheck until that user manually confirms they have fixed it. A success still renews 60 days. retrieve_failed is unchanged: retry later the same day, do not lapse, do not wait for a manual confirm.
- 2026-10-09: An immediate URL check runs on the client first, from the user’s IP. The server fetches that URL only if the client check succeeded. If the client returns tag_missing or retrieve_failed, the server does not fetch. A scheduled 60-day check is server-only. Immediate rechecks of the same URL by the same account are limited to once per 24 hours. A repeat inside that window is rejected and does not fetch.
- 2026-10-19: **No custody** (review option B). VoteMap never holds USDC. A vote is a **pledge**: a wallet-signed promise (pot, amount ≥ 1 USDC, expiry ≤ 365 days), no gas, USDC stays in the wallet. A **pay** is one transaction from the voter’s wallet through a PayRouter that holds nothing: 98.5% to the payee’s payout wallet, 1.5% to the treasury. **1.5% on pay is the only fee**; pledge, cancel, and lapse are 0%. No escrow, factory balance, shop credit, redeem step, vest, clawback, restake, move, early leave, or expiry fee. Shops are paid directly for a listed product. Supersedes the 2026-10-03 shop credit, redeem, and money trail entries where they conflict.
- 2026-10-19: Incentives without escrow: pots show **backed** USDC (pledges count only up to the wallet’s balance, pro rata; revoked badge backs $0). Every account shows **follow-through** (paid ÷ pledged on ended pledges where another account paid a claimant). Claims are off-chain posts by verified-bind accounts. VoteMap never chases an unpaid pledge. Tuning is open (*Pledge reliability*, *Wash pays*).
- 2026-10-19: **Nothing personal on-chain.** No OIDC `sub`, email, name, gender, birth year, phone, or any hash of them. On-chain is wallets, `potId`, amounts, fee, `productId`, payer country, used nonces.
- 2026-10-19: **Fetcher is isolated.** All outbound fetches run in a fetcher with no secrets and no route to private networks. Non-public addresses (loopback, RFC 1918, link-local and metadata, CGNAT, reserved, IPv6 equivalents) are rejected, DNS is pinned per connection, every redirect is re-checked. Signing key lives in KMS / HSM. Supersedes the 2026-10-09 “address only the signer can reach is still fetched” entry.
- 2026-10-19: **Pay signature:** EIP-712 domain with chainId and router; struct binds payer (= `msg.sender`), potId, to, amount, productId, price, nonce (used once), deadline. One payee per pay; no loops over payees.
- 2026-10-19: **No payouts to public officials,** candidates, their staff or immediate family, or anything they control. Payee attestation, signer refusal for bound handles on public officials lists, and no pots that pay for votes. Payees are screened against officials; payers are not. Supersedes the 2026-10-03 entry that left PEP and politician payees open.
- 2026-10-19: **No trail score.** Dropped: every money-path wallet is a votemap wallet, so it was always about 100%. Pay rows come only from `Paid` events. The indexer is a free scheduled job (own-contract logs + Multicall balances on free RPC). Supersedes the score in the 2026-10-03 money trail entry.
- 2026-10-19: **Binds.** Only a **verified** bind blocks “already claimed”; pending binds never block. A due bind with `retrieve_failed` for **7 days in a row** becomes **unverifiable** (bound, not pickable) until a check succeeds. All URL checks are **server-side**; the client-first check is removed (browser JS cannot read those pages because of CORS). Immediate checks keep the 24-hour same-URL limit and are rate-limited per account, IP, and host. Supersedes the 2026-10-09 client-then-server entries.
- 2026-10-19: **Votemap handles are permanent.** No rename, no release, so trail rows always name the account that acted.
- 2026-10-19: **Biometrics prove a live human, not device ownership.** Pledge and pay stay in the native app (Capacitor shell). Biometric-only hardware key, destroyed when biometrics change, attested at enroll (App Attest; Android Key Attestation + Play Integrity), fresh biometric per action on a challenge bound to the action. No PIN, passcode, Windows Hello PIN, or browser passkey. Uniqueness still comes from Coinbase KYC.
- 2026-10-19: **Hybrid bind.** X and TikTok: a post carrying `votemap/@handle` or `votemap.net/handle`, read through the free oEmbed endpoints; bind is for the oEmbed author; the post must stay up. Threads: Threads API OAuth (`threads_basic`, app review), token KMS-encrypted, recheck via `/me`. Instagram: bio, unchanged, with the 7-day ceiling. Still no comment fallback, no cold-DM, no paid X API, no other OAuth. Supersedes bio-only for X, TikTok, and Threads.
- 2026-10-19: **No phone, no SMS OTP.** Coinbase KYC on every money-path wallet is the uniqueness anchor; up to 3 votemap accounts per KYC’d person is accepted. Re-enroll uses Google/Apple + a mapped-wallet signature + 72-hour wait with email notice.
- 2026-10-19: **Gender and birth year are optional analytics,** self-reported, asked after the first pledge, off-chain, aggregates of at least 20 accounts only, never on the public page.
- 2026-10-19: **Smart wallets supported** (ERC-1271 / ERC-6492) to drop seed phrases and extensions from signup. Coinbase Onchain Verify on a smart-wallet address still needs a live test.
- 2026-10-19: **Payout change protection.** Mapping a wallet or changing payout needs phone biometrics plus either the current payout wallet’s signature or a 72-hour wait with an email that can cancel it.
- 2026-10-20: **TikTok binds with Login Kit** (free; `user.info.basic` + `user.info.profile`, read-only, pre-approval for the username scope), not post-a-token. X stays on free oEmbed post-a-token; Sign in with X is a paid profile read (~$0.01) and is only the fallback. Instagram personal accounts have no login API (Basic Display shut down 2024-12-04), so bio stays.
- 2026-10-22: **No percentage steers behavior.** Incentives are structural: accepted claim = paid by pledgers holding ≥ ⅓ of the pot’s backed USDC; public disputes; follow-through split paid / disputed / silent; pays returned to the payer’s wallets within 30 days excluded; concentration shown; expected payout with shrinkage toward the average (k = $100). All thresholds dollar-weighted. Draft pricing: no fee, optional un-prefilled tip at pay (pending Isaac’s choice).
- 2026-10-22: **No pot-level verdict.** Isaac: a ⅓-of-backed “accepted claim” lets a whale decide for everyone, and outcomes are subjective (ice cream vs gelato). Replaced it: each pledger judges alone; paying any payee keeps the pledge; pledgers can decline with a public reason; follow-through = paid / declined / silent over pots someone else claimed; pots show a claim split for information only.
- 2026-10-22: **Website check uses owner-only places.** Isaac spotted that a tweet with the token would verify x.com. The string now counts only in a DNS TXT record at `_votemap.<host>` or at `https://<host>/.well-known/votemap.txt`; the verified link is the exact host, never a path.
- 2026-10-22: Resolved from review: pot key = network + post id; snapshot card forever, “edited” marker, private/deleted refuses new pledges but allows pays; signer checks catalog price; any verified social of the payee can be picked; trail rows store social @ + platform id at that moment; stop = signer refuses pledges and pays, illegal content only, public log with a daily hash on Base; Coinbase 18+ answers the age check; re-enroll answers lost phone.
